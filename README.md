# Viscosity of Liquid Water: A Least Squares Method Report

A technical report deriving and comparing three mathematical models (linear, polynomial, and exponential) to fit the relationship between temperature and the viscosity of liquid water, using the least squares method.

## Note on Scope

This is a mathematical modeling report for a Linear Algebra course, not a coding project. All curve fitting was derived and solved by hand using least squares equations; there is no accompanying code implementation.

## Overview

Using a dataset of temperature and corresponding viscosity measurements, three candidate models were fit using least squares:

- **Linear model**: y = a₀ + a₁x
- **Polynomial model**: y = a₀ + a₁x + a₂x²
- **Exponential model**: y = αe^(βx)

Each model's coefficients were derived by solving the normal equations from the least squares method, and the resulting fits were compared to determine which model best describes the temperature-viscosity relationship.
